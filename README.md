## Overview

This repository contains three main projects: **CHAPS**, **Quizard** and **Autowash**. Each project includes all necessary PHP, CSS, HTML files, images, and respective SQL database files for setting up and running the applications.

To run on localhost, make sure the app folder is located in your local development environmet (XAMPP, Laragon, or others) 
and the respective [app_name].sql is imported to a phpMyAdmin database with the same [app name].
